# YASNO OS Vault v1.0

Готовая стартовая база знаний ЯСНО для Obsidian.

## Как открыть
1. Распакуйте архив.
2. Откройте Obsidian.
3. Выберите **Open folder as vault**.
4. Укажите папку `YASNO_OS`.
5. Начните с `00_SYSTEM/YASNO_OS.md`.

## Важно
Стартовые сведения собраны из уже зафиксированного контекста ЯСНО, но изменяемые цифры необходимо сверять с первичными данными.

## Рекомендуемый следующий этап
Спроектировать и протестировать `Второй мозг ЯСНО v2.0`, который будет работать поверх этой структуры.
