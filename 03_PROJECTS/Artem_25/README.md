# Видео к 25-летию Артёма

Локальный производственный пакет проекта. Папка предназначена для размещения внутри Obsidian Vault `YASNO_OS` и синхронизации через приватный репозиторий `gusovruslan-cmyk/yasno-os`.

## Главные файлы

- `00_Канон_проекта.md` — обязательные правила внешности, одежды, света и continuity.
- `01_Сценарий.md` — утверждённые сцены и хронометраж.
- `02_Реестр_кадров.md` — соответствие номеров кадров файлам и статусам.
- `03_Промпты_Vidu.md` — утверждённые правила и готовые промпты анимации.
- `References/` — эталоны персонажа, дома, семьи и локаций.
- `Master_Frames/` — утверждённые мастер-кадры по сценам.
- `Source_Media/` — исходные фотографии и видео.
- `Archive/Recovered_All/` — восстановленный архив без удаления спорных версий.

## Правило начала каждой рабочей сессии

Перед созданием или изменением кадров прочитать:

1. `00_Канон_проекта.md`
2. `02_Реестр_кадров.md`
3. карточку нужной сцены в `01_Сценарий.md`

Не брать изображения из `Archive` как утверждённые без проверки реестра.
